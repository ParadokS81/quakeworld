# docs-web (docs.quake.world)

**Status:** Paused -- waiting on vikpe's DNS greenlight for `docs.quake.world` (the root `HANDOVER.md` ongoing-arc row); the preview deploy at `quakeworld-docs.pages.dev` serves meanwhile. Open work: root `HANDOVER.md`.

The Layer 1 reference for the QuakeWorld ecosystem, projected per codebase from the QW Oracle: a static VitePress site (Vue, Tailwind, daisyUI, MiniSearch for the global entity search) built from the per-codebase JSON snapshots in `data/`, which qw-oracle's `build-docs-snapshot` writes. Its own pnpm subtree; the scripts are `docs:dev`, `docs:build`, `docs:preview` and `test`.

Rules in this scope:
- `data/*.json` is generated by qw-oracle. Regenerate there (`apps/qw-oracle/OVERVIEW.md`, snapshot distribution); never hand-edit.
- Routes are generated: `[codebase].paths.ts` and `[codebase]/[type].paths.ts` enumerate the snapshots, so a new codebase is a new snapshot file, not a route edit.
