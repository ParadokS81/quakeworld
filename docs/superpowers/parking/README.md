# Parking

Parked arcs: work the operator wants, not yet designed, at any clarity. One entry per parked arc, a folder `YYYY-MM-DD-<topic>/README.md` opening with the Status block the arc board reads (`- **Stage:**` parked | designing | designed | planning, `- **Idea:**`, `- **Sparked by:**`, `- **Spec:**`, `- **Plan:**`), side material beside the README; the date is when the entry was opened, not last touched. The shape and the park procedure are harness-lab `DOC-WRITING.md`'s "Parking doc" entry (sitting 2026-10-14): read the project's parked docs first, sort the wish (a note in an existing doc, a Small followup, or new), and open a new doc on the operator's word.

A parking doc carries no phase state; the Stage line is its one lifecycle word. Live phase state belongs to an arc scaffold's Status block, never here. Dated notes are appended under `## Notes` naming their source; a ruling recorded here is not in the spec until it is drafted there. No `## Future arcs` row indexes it: the board lists it from its block until its plan exists, then the plan. A paused arc's `## Ongoing arcs` row may still anchor on an older flat doc here.

A parking doc leaves by deletion: at the arc's close in the docs pass, the `arc-history.md` paragraph naming it, or when dropped, folded or found duplicated, in one scoped commit saying which. "Kept as a record" is not a disposition. Flat `YYYY-MM-DD-<topic>.md` files with no Stage block are older captures no row names any more, the cleanup pile; the docs-check walk flags them as orphans.
